

# Growflix

Growflix é uma plataforma web inspirada em serviços de streaming, que reúne todo o conteúdo produzido pela Growdev em um só lugar. Aqui você encontra podcasts, webinars, lives e outros vídeos educativos sobre tecnologia, carreira e design.

## Funcionalidades

- Interface moderna e responsiva, baseada em Bootstrap;
- Catálogo de vídeos organizados por categorias: Growcast, Webinars, Jornada UX/UI e Diversos;
- Player de vídeo integrado via YouTube;
- Modal para exibição dos vídeos sem sair da página;
- Navegação intuitiva entre as seções;
- Totalmente gratuito e aberto para todos os públicos.

## Estrutura de Pastas

```
Growflix-main/
│
├── assets/         # Imagens e logos do projeto
├── css/            # Arquivos de estilo (style.css)
├── html/           # Página principal de vídeos (home.html)
├── js/             # Scripts JavaScript (data.js, home.js, index.js)
├── index.html      # Landing page inicial
└── README.md       # Documentação do projeto
```

## Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)
