

# Growflix

Growflix é uma plataforma web inspirada em serviços de streaming, que reúne todo o conteúdo produzido pela Growdev em um só lugar. Aqui você encontra podcasts, webinars, lives e outros vídeos educativos sobre tecnologia, carreira e design.

## Funcionalidades

- Interface moderna e responsiva, baseada em Bootstrap;
- Catálogo de vídeos organizados por categorias: Growcast, Webinars, Jornada UX/UI e Diversos;
- Player de vídeo integrado via YouTube;
- Modal para exibição dos vídeos sem sair da página;
- Navegação intuitiva entre as seções;
- Totalmente gratuito e aberto para todos os públicos.

## Estrutura de Pastas

```
Growflix-main/
│
├── assets/         # Imagens e logos do projeto
├── css/            # Arquivos de estilo (style.css)
├── html/           # Página principal de vídeos (home.html)
├── js/             # Scripts JavaScript (data.js, home.js, index.js)
├── index.html      # Landing page inicial
└── README.md       # Documentação do projeto
```

## Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)

## Como Executar o Projeto

1. Clone ou baixe este repositório;
2. Abra o arquivo `index.html` em seu navegador;
3. Navegue pelo conteúdo e aproveite os vídeos!

Não é necessário nenhum servidor ou instalação de dependências.

## Sobre os Arquivos

- **index.html**: Página inicial com informações, perguntas frequentes e botão de acesso ao catálogo;
- **html/home.html**: Página principal dos vídeos, com navegação por categorias e player modal;
- **js/data.js**: Lista dos vídeos disponíveis, com título, imagem, link e categoria;
- **js/home.js**: Scripts para renderização dinâmica dos cards de vídeo e funcionamento do modal;
- **css/style.css**: Estilos customizados para layout, responsividade e animações;
- **assets/**: Logos, banners e imagens utilizadas no site.
